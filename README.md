# Urban Style & Streetwear Catalog 👟🔥

A high-end, responsive web showcase designed for urban fashion brands. This project focuses on high-impact visual storytelling, seamless navigation, and a direct lead-capture system.

## ✨ Key Features
*   *Curated Product Gallery:* A clean and stylish catalog layout designed to highlight apparel details.
*   *Custom Inquiry Form:* A streamlined contact section where users can provide their name, email, and project specifics.
*   *Urban Aesthetic:* Modern UI/UX with a focus on typography and bold imagery to match street culture.
*   *Fully Responsive:* Optimized for a flawless experience on smartphones and tablets (essential for fashion shoppers).

## 🛠️ Tech Stack
*   *HTML5:* Semantic markup for better SEO.
*   *CSS3:* Custom animations, Flexbox, and Grid for a sophisticated layout.
*   *JavaScript (ES6+):* Dynamic interaction and form validation.

## 📁 Project Structure
The code is organized for scalability:
- /assets: Images and branding assets.
- /css: Modular stylesheets.
- /js: Logic for the catalog and contact form.
